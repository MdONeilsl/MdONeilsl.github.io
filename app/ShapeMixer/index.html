Shape Mixer

Tool for mixing Second Life avatar shapes with precision and ease

Shape Mixer Interface

Application ready

Upload your avatar shape XML files to begin mixing and customizing your appearance. Each file can contribute different body parts to the final shape.

Select at least one category from loaded files to enable generation

Instructions

  1. Exporting Shapes:
    • Open Second Life and navigate to: Develop → Avatar → Character Tests → Appearance
    • Select the shape you want to export and click "Export to XML"
    • Save the XML file to your computer
  2. Mixing Shapes:
    • Upload multiple shape XML files using the interface above
    • Select which body parts to use from each uploaded shape
    • Only one shape can contribute to each body part category
    • Click "Generate Mixed Shape" to create and download your custom shape
  3. Importing Shapes:
    • In Second Life, open the Shape Editor (Appearance → Shape)
    • Click the "Import" button in the bottom right corner
    • Select your generated mixed shape XML file
    • The new shape will be applied to your avatar immediately
